# sudoberlin.github.io

Personal site of Shubham Singh. Robot learning, manipulation and human-robot interaction.

Live at https://sudoberlin.github.io

Plain HTML and CSS, no build step. The only JavaScript is on the unlisted `learning/` page, which saves progress in the browser. Edit `index.html` for content and `style.css` for layout, then push to `main`. GitHub Pages republishes within a minute or two.

Preview locally with `python3 -m http.server 8000` and open http://localhost:8000.
