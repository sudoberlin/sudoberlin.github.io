    How the plan works

    Most of the time goes into building with C++ and Python in ROS 2, MoveIt, Nav2, perception pipelines, simulators and robot learning frameworks. Everything runs in simulation, with no electronics. A 30 minute math thread (transforms, kinematics, Jacobians, control) runs alongside weeks 1 to 8.

    • 1.5 h
      Concept. Official docs, tutorial or lecture for the day's topic.
    • 3 h
      Build. Write the node, plugin or pipeline myself, in C++ where the ecosystem uses C++.
    • 0.5 h
      Read real code. Source from MoveIt 2, Nav2, ros2_control or LeRobot.
    • 1 h
      Math thread and log. Modern Robotics in weeks 1 to 8, then a short log entry and a push to GitHub.

    Sunday is for the weekly deliverable, its README and a short demo GIF.
